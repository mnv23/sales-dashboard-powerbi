## 🚖 Uber Ride Bookings Analytics Dashboard

An interactive **Power BI dashboard** analyzing Uber ride booking data (NCR/India region), covering trip volume, revenue, cancellations, and customer/driver ratings across different vehicle categories.

### 📊 Dashboard Pages
- **Overall** – Booking trend over time and status breakdown
- **Vehicle Types** – Total & successful bookings, avg./total distance by vehicle category: Go Mini, Go Sedan, Uber XL, Prime Sedan, Auto, Bike, E-Bike
- **Revenue** – Booking value trends over time and by category
- **Cancellation** – Cancellation %, and reasons split by customer vs driver
- **Rating** – Average driver and customer ratings by vehicle type

### 🔑 Key Metrics
- Total Bookings & Booking Status
- Booking Value / Revenue
- Ride Distance (avg & total)
- Cancellation % (customer vs driver-initiated)
- Customer & Driver Ratings
- Payment Method distribution

### 🛠️ Tools Used
Power BI Desktop (data modeling, DAX, report design), Power Query (data cleaning), DAX (Cancel %, ratings), custom slicers, KPI cards, pie/line/column charts, and button-based page navigation.
